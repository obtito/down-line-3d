# 羽绒水洗生产线 · 3D 结构复原模型

单文件 Three.js 应用，依赖全部内联，离线可用。

- 五道工序：水洗 → 脱水 → 烘干 → 冷却 → 分拣。
- 4500 片羽毛共用一个粒子池，身份、质量、外形、颜色与尺寸贯穿全过程，设备与管道连续交接。
- 四个直立分拣箱沿风向由矮到高排列：越轻的羽毛飞得越高、越远，进入对应箱子后旋转飘落。
- 左上角独立蓝色按钮可收起或展开控制面板。
- 面板内可独立调整镜头切换时长（0.6～4 秒）和羽毛速度（0.5～4 倍），默认 1.8 秒与 3 倍。
- 「工艺巡览」依次展示五台主机，面向视角的设备表面自动变透明。
- 左键旋转、滚轮缩放、右键平移；点击设备查看结构说明。

设备结构和运动参数用于工艺原理示意。
